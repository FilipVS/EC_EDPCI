## Battery / RF fit (⚠️ inference only — no source mentions batteries or RF)
- No source uses the terms battery, radar, RF. Everything below is *my reasoning* from scope text, to be tested with CZ contacts.
- **DECODER** ⚠️ — highest plausibility for batteries (UAS/counter-UAS power, unmanned systems) and RF (C-UAS detection/jamming, datalinks). ✅ CZ participates. "Expand relevant industrial production capacity" suggests supplier ramp-up.
- **EFW** ⚠️ — drone defence + C4ISTAR + AMD pillars → RF/sensors; battery for unmanned/field systems. ✅ CZ participates. Short-term actions → nearest-term demand.
- **EU-FIAMD** ⚠️ — "sensors, effectors, C2" → RF (radar/comms/EW) subsystem supply; massive size but 2040 horizon and prime-led architecture. ✅ CZ participates.
- **SPACE** ⚠️ — SATCOM/PNT/NAVWAR/SIGINT → RF payload/ground segment; battery only for satellites/space-grade (niche). ✅ CZ participates.
- **IMSD** ⚠️ — unmanned underwater/surface systems → batteries; but ✅ **CZ not a participant** → lowest priority for a Czech firm (still reachable as a subcontractor to a foreign prime, speculatively).
